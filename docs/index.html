Self-hosted. Agent-first. Approved by people.

Your go-to-market, run by agents you can trust.

GTM OS is a self-hosted operating system for go-to-market that keeps one typed record of who you sell to, runs the engines that find, score, route and reach them, and lets your agents act only after a second person approves.

Four gains, from the first day

Built for GTM engineers who wire the system and strategists who run it.

One source of truth for who you sell to

Accounts, contacts, deals and signals live in one typed model. Your ICP, scoring and voice are defined once, and every engine obeys.

Agents that never act alone

Anything that leaves the building waits for a second person. The proposer can never approve their own action.

Install and upgrade

You need Docker Desktop, Node 22 or later, and Claude Code, which runs the setup with you.

Install

$ npm i -g @gtmos/cli
$ mkdir my-gtm && cd my-gtm
$ gtm init

Release 0.2.5 (rolling out). Until it is published, this installs the previous release.

Open Claude Code in that folder and run /setup-gtmos. Claude asks only for what a person has to provide.

Upgrade

$ npm i -g @gtmos/cli@latest
$ gtm upgrade --check
$ gtm upgrade --channel stable --yes

Release 0.2.5 (rolling out). Until it is published, this upgrades to the previous release.

Upgrade the CLI first. Upgrades snapshot your data first, and --dry-run rehearses one. A pinned install only moves when you choose --channel or --to.
